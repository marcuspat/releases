<html><head></head><body><h1>TurboFlow 4.0.0 Release Notes — The Ruflo Migration</h1> <p><strong>Release Date:</strong> March 7, 2026 <strong>Previous Version:</strong> v3.4.1 (February 2025)</p> <hr> <h2>Summary</h2> <p>TurboFlow 4.0 is a complete rebuild. Claude Flow graduated to Ruflo v3.5 after 5,800 commits and a rename. Every package reference, alias, and integration point in TurboFlow has been rewritten to match. The setup script went from 15 steps installing ghost packages to 10 steps installing what actually exists.</p> <p>Three new systems fill gaps that v3.x never addressed: Beads gives agents memory that survives between sessions, GitNexus gives agents structural awareness of the codebase before they touch it, and native git worktrees give each parallel agent its own isolated workspace.</p> <hr> <h2>By the Numbers</h2>

<hr> <h2>Known Issues</h2> <ul> <li>Ruflo's <code>--wizard</code> flag may fall back to non-interactive <code>init</code> in headless environments (DevPod, Codespaces). The setup script tries both.</li> <li>Beads <code>bd init</code> requires the workspace to be a git repository.</li> <li>GitNexus indexing runs in the background on <code>wt-add</code> — large repos may take a moment.</li> </ul> <hr> <h2>What's Next</h2> <ul> <li><strong>v4.1</strong>: OpenFang Hands integration — autonomous agents for research, lead gen, social posting, competitor monitoring per business entity</li> <li><strong>v4.2</strong>: Open WebUI 4-instance deployment automation (Rackspace Spot)</li> <li><strong>v4.3</strong>: Per-entity CLAUDE.md and knowledge base customization</li> </ul> <hr> <p><em>"The tools change.
