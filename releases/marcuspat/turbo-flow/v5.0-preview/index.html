v5.0-preview — the rig era (private beta open)

Sep 22, 2026 · Shell

Turbo Flow continues as Turbo Rig — a thin agentic coding rig: cross-model review gate, git-versioned memory, a written constitution. The full rig runs in private beta: request access at https://turbo-rig-beta.vercel.app.

What's in this release

rig-lite/ — the governance layer your agentic environment is missing, drop-in for turbo-flow v4 or any repo:

  • gate.sh — fail-closed cross-family review gate: deterministic checks first (free), then a reviewer from a different model family must end with a parseable verdict. Nonce-fenced diff (a diff can't inject its own APPROVED), --no-exec mode + 600s hang caps for untrusted branches, secret-redacted output, --base misuse fails closed. It earned this: the script itself survived ~35 review rounds by a model family that didn't write it — every finding became a self-test.
  • constitution.md — the four laws as a fill-in template.
  • memory.md — the git-versioned memory pattern + diagrams.
  • self-test.sh — the fail-closed proof. Run it before you trust it.

Fresh-install fixes, verified in a clean Codespace: bare npx hung headless installs at npm's confirmation prompt — 66 sites fixed (npx -y); rust feature pinned to the current concrete latest. Full 11-step install chain runs clean end-to-end; tf-verify.sh passes the stack.

Demo: demo/rig-lite-demo.gif — recorded in that Codespace (install → self-test → live REVISE→fix→APPROVED gate run; reviewer stubbed, no API keys).

The v4 Ruflo-era environment and devcontainer seed remain below the fold, unchanged.

Next stop: the public rig.
