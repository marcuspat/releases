v3.0

Alpha 3.0.4

Mar 7, 2026 · Shell

TurboFlow v3.0.4 is a bugfix and cleanup release. The main changes are corrections to the setup script — the non-existent skill install command has been removed (skills are built-in to Claude Flow, not installed separately), the plugin subcommand was fixed to plugins, and Claude Code installation now has an npm fallback if the primary method fails. MCP config creation also has a manual fallback when claude mcp add doesn't cooperate.

On the housekeeping side, Unicode characters that caused terminal rendering issues have been stripped, set -x verbose output was removed from post-setup.sh, and the installation steps were streamlined from 18 to 15. The full stack remains the same: 36 built-in skills, 15 plugins, 175+ MCP tools, 60+ agents. Nothing was added or removed — this release just makes what was already there actually install correctly.
