v5.1.0 — rig-lite: the complete portable rig

Sep 28, 2026 · Shell

The v5.1 release: rig-lite graduates from a 4-file governance kit to a complete portable rig — nine files, ten minutes, no new dependencies. Everything here was extracted from the running private beta, not designed in the abstract: the beta builds continuously, and this is the first versioned sync point.

The three waves (each gated cross-family, each merged by a human)

| wave | PR | what landed | |---|---|---| | 1 | #56 | wt.sh isolated worktrees · spec + UAT templates · init-repo.sh one-command onboarding | | 2 | #57 | gate v2: --pr <n> posts verdicts as PR comments (GitHub is the state machine) · --sweep gates every ungated open PR (author-attributed: a marker typed by anyone else is not a verdict) · -C <repo> honored by every mode | | 3 | #58 | 9-task automations pack (morning digest, security scan, memory consolidation, retro, repo-hygiene pass, site sentinel, gate canary, portability canary, nightly sweep) · digest.sh fleet health with fixture-tested parsers · per-verdict gate log the digest joins · README EN/ES reframe |

Why trust it

  • 166 self-test checks, ALL PASS under bash 5.3 and stock macOS 3.2; shellcheck clean at warning severity
  • The kit's gate survived 16 review rounds before its first APPROVED; the v5.1 waves survived their own gates too — the catches became tests (heredoc command-subjection from a project name, --clean ../../x path traversal, spoofable sweep markers, cron-locale crashes, false all-clears)
  • Fail-closed everywhere: ambiguity is REVISE, humans hold the merge button

Full rig (gate + constitution + memory + automations, integrated and always-on): running in private beta → turbo-rig-beta.vercel.app
